# บันทึกงานธุรการ — โรงเรียนชุมชนวัดไทยงาม

Web app บันทึกการทำงานประจำวันของเจ้าหน้าที่ธุรการ และออกเอกสารเบิกค่าจ้างรายเดือน
(ใบส่งมอบงานจ้าง · ใบตรวจรับงานจ้าง · แบบรายงานผลการปฏิบัติงาน) เป็นไฟล์ Word

- หน้าเว็บ: HTML + JavaScript + Tailwind บน GitHub Pages (ไม่มี build step)
- ฐานข้อมูล: Google Sheets ผ่าน Google Apps Script (`gs.js`)
- Word: docx.js

## ความสามารถของระบบ

เว็บแอปสำหรับ **เจ้าหน้าที่ธุรการ**, **นักการภารโรง** และ **พี่เลี้ยงเด็กพิการ** ของโรงเรียนชุมชนวัดไทยงาม
ใช้บันทึกงานที่ทำในแต่ละวัน แล้วออกเอกสารเบิกค่าจ้างประจำเดือนเป็นไฟล์ Word ได้เลย

### 1. หน้าหลัก
- ทักทายด้วยชื่อ และบอกว่าวันนี้บันทึกงานแล้วหรือยัง
- สรุปตัวเลขของเดือนนี้ เช่น จำนวนวันทำงาน และจำนวนวันลา (ลากิจกับลาป่วยรวมกัน)
- แสดงรายการที่บันทึกล่าสุด
- บอกว่าวันทำการไหนในเดือนนี้ที่ยังไม่ได้บันทึก จะได้ไม่ลืม
- มีปุ่มลัด "บันทึกงานวันนี้" และ "ออกรายงาน"

### 2. บันทึกการทำงาน
- บันทึกงานของวันนี้หรือย้อนหลังได้ มีปุ่มเลื่อนไปวันก่อนหน้าและวันถัดไป
- เลือกสถานะของวันได้ 4 แบบ คือ ทำงาน, วันหยุด, ลากิจ และลาป่วย
- ถ้าเป็นวันหยุด ใส่เหตุผลได้ เช่น วันปิยมหาราช ข้อความนี้จะขึ้นเป็นแถวสีแดงในรายงาน
- เพิ่มรายการงานได้หลายรายการ แต่ละรายการมีรายละเอียดงาน จำนวน และหน่วย
- ใส่หมายเหตุประจำวันได้ เช่น ไปราชการที่ สพป.
- มี **งานที่ใช้บ่อย** กดทีเดียวก็เพิ่มเป็นรายการได้ทันที
- ถ้าวันนั้นบันทึกไว้แล้ว จะแก้ไขหรือลบก็ได้

### 3. ปฏิทิน
- ดูทั้งเดือนในรูปปฏิทิน แต่ละวันมีสีตามสถานะ
- กดที่วันเพื่อดูรายละเอียด หรือเข้าไปแก้ไข
- มีสรุปของเดือนแสดงอยู่ข้างปฏิทิน

### 4. ออกรายงานประจำเดือน
- สร้างเอกสารได้ 3 แบบ และเลือกได้ว่าจะออกแบบไหนบ้าง
  - ใบส่งมอบงานจ้าง
  - ใบตรวจรับงานจ้าง
  - แบบรายงานผลการปฏิบัติงาน
- เลือกเดือนและปี พ.ศ. หรือกำหนดวันเริ่มและวันสิ้นสุดเองได้
- เลือกได้ว่าจะใช้เลขอารบิกหรือเลขไทย
- กรอกข้อมูลกล่องรับเลขที่ที่มุมขวาบน ได้แก่ เลขที่รับ วันที่ และโรงเรียน
- ใส่จำนวนเงินที่ขอเบิกและภาษีหัก ณ ที่จ่าย ระบบจะคำนวณยอดคงจ่ายจริง และเขียนจำนวนเงินเป็นตัวหนังสือภาษาไทยให้เอง
- ดูตัวอย่างเอกสารขนาด A4 ได้ก่อนส่งออก
- ส่งออกเป็น **Word (.docx)** ถ้าต้องการ PDF ให้เปิดไฟล์ Word แล้วบันทึกเป็น PDF

### 5. ตั้งค่า
- ข้อมูลผู้รับจ้าง เช่น ชื่อ ตำแหน่ง ค่าจ้าง และเลขที่สัญญา ระบบจะนำไปเติมในเอกสารให้เอง
- ข้อมูลผู้ลงนามในเอกสาร เช่น ผู้ควบคุมงาน
- เพิ่มหรือแก้ไขรายการงานที่ใช้บ่อย
- ใส่ URL ของ Google Sheet และกดทดสอบการเชื่อมต่อได้

### 6. ความสามารถอื่น ๆ
- **ใช้ได้หลายตำแหน่ง:** สลับระหว่างธุรการ นักการภารโรง และพี่เลี้ยงเด็กพิการได้ ข้อมูลของแต่ละตำแหน่งเก็บแยกกันคนละ Google Sheet
  หรือเปิดตรงไปที่ตำแหน่งนั้นด้วยลิงก์ `?staff=admin`, `?staff=janitor` หรือ `?staff=nanny`
- **เปิดและสลับตำแหน่งได้เร็ว:** เว็บจำข้อมูลล่าสุดของแต่ละตำแหน่งไว้ในเบราว์เซอร์ แสดงได้ทันทีแล้วค่อยโหลดข้อมูลใหม่จาก Sheet อยู่เบื้องหลัง
  ส่วน Apps Script ก็เก็บผลอ่าน Sheet ไว้ช่วงหนึ่งเพื่อให้ตอบเร็วขึ้น
- **เก็บข้อมูลใน Google Sheets** ผ่าน Google Apps Script จึงไม่ต้องมีเซิร์ฟเวอร์เอง
- **โหมดทดลอง:** ถ้ายังไม่ได้ใส่ URL ข้อมูลจะเก็บไว้ในเบราว์เซอร์ ใช้ลองระบบได้ แต่ข้อมูลส่วนนี้จะไม่ถูกย้ายไป Google Sheet
- **ใช้บนมือถือได้:** บนมือถือเมนูจะอยู่แถบล่างของจอ
- **ไม่ต้องติดตั้ง:** วางไฟล์บน GitHub Pages ก็ใช้งานได้เลย

### ข้อจำกัดที่ควรรู้
- ระบบไม่มีการเข้าสู่ระบบ (login) ใครได้ URL ของ Apps Script ไปก็อ่านและแก้ข้อมูลได้ จึงไม่ควรเผยแพร่ลิงก์นี้
- เครื่องที่จะเปิดไฟล์ Word ต้องติดตั้งฟอนต์ TH SarabunPSK
- เปิดเว็บครั้งแรกในแต่ละเครื่องอาจรอ 3–5 วินาที (หรือนานกว่านั้นถ้า Apps Script ไม่ได้ใช้มานาน) ครั้งต่อไปจะขึ้นทันที

## ติดตั้ง

### 1. Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ แล้วไปที่ **ส่วนขยาย > Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางโค้ดทั้งหมดจาก `gs.js` จากนั้นกดบันทึก
3. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** ครั้งแรกจะขอสิทธิ์ ให้กดอนุญาต ระบบจะสร้างชีต Days, Items, Settings และ Presets ให้
4. **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท: เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` แล้วเปิด `URL?action=ping` ในเบราว์เซอร์ ต้องได้ `{"ok":true,...}`

### 2. เว็บ
เลือกวิธีใดวิธีหนึ่ง
- ใส่ URL ใน `assets/js/config.js` ที่ `API_URL: '...'` (ใช้ได้ทุกเครื่อง) หรือ
- เปิดเว็บ ไปที่หน้า **ตั้งค่า > การเชื่อมต่อ Google Sheet** วาง URL แล้วกด **บันทึก URL** (ค่านี้จำไว้เฉพาะเบราว์เซอร์นั้น)

ถ้ายังไม่ได้ใส่ URL เว็บจะทำงานใน **โหมดทดลอง** และเก็บข้อมูลในเบราว์เซอร์ ใช้ลองระบบได้ แต่ข้อมูลจะไม่ถูกย้ายไป Google Sheet ให้

### 2.1 เพิ่มตำแหน่งนักการภารโรง (Sheet แยก)
เว็บเดียวบันทึกได้ทั้ง **ธุรการ** และ **นักการภารโรง** สลับได้จากเมนู "กำลังบันทึกของ" ที่แถบซ้าย (มือถืออยู่แถบบน) ข้อมูลของแต่ละตำแหน่งอยู่คนละ Google Sheet
1. สร้าง Google Sheet ใหม่อีกไฟล์ เช่น "บันทึกงาน นักการภารโรง" แล้ววางโค้ด `gs.js` ชุดเดียวกัน
2. รันฟังก์ชัน **`setupJanitor`** แทน `setup` ระบบจะตั้งตำแหน่งเป็น "นักการภารโรง" และใส่รายการงานที่ใช้บ่อยของนักการภารโรงให้
3. Deploy เป็นเว็บแอปแบบเดียวกับข้อ 1
4. ใส่ URL ใน `assets/js/config.js` ที่ `PROFILES` ของ `janitor` หรือสลับไปนักการภารโรงในเว็บแล้วใส่ในหน้าตั้งค่า
5. เปิดหน้าตั้งค่าขณะเลือกนักการภารโรง แล้วกรอกชื่อ ค่าจ้าง เลขที่สัญญา และผู้ควบคุมงานของนักการภารโรง

### 2.2 เพิ่มตำแหน่งพี่เลี้ยงเด็กพิการ (Sheet แยก)
ทำเหมือนข้อ 2.1 แต่รันฟังก์ชัน **`setupNanny`** แล้วใส่ URL ใน `assets/js/config.js` ที่ `PROFILES` ของ `nanny`
(ห้ามใช้ URL ซ้ำกับตำแหน่งอื่น ไม่อย่างนั้นข้อมูลจะปนกัน)

เปิดตรงไปที่ตำแหน่งใดตำแหน่งหนึ่งได้ด้วยลิงก์ `…/?staff=admin`, `…/?staff=janitor` หรือ `…/?staff=nanny`

### 3. GitHub Pages
1. Push ไฟล์ทั้งหมดขึ้น repo (ไม่ต้องใส่ `plan-test.html` ก็ได้)
2. **Settings > Pages > Deploy from a branch** เลือก `main` และ `/ (root)`
3. เปิด `https://<user>.github.io/<repo>/`

> ถ้าแก้ `gs.js` ภายหลัง ต้องไปที่ **จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชัน: ใหม่** URL เดิมจึงจะใช้โค้ดใหม่

## โครงสร้างไฟล์
```
index.html               หน้าเว็บ
assets/css/app.css
assets/js/config.js      API_URL, ฟอนต์ Word
assets/js/thai.js        วันที่ไทย เลขไทย bahtText ตัดคำไทย
assets/js/api.js         เรียก Apps Script / โหมดทดลอง / Store
assets/js/ui.js          ไอคอน toast modal
assets/js/app.js         เมนู หน้าหลัก เริ่มระบบ
assets/js/record.js      บันทึก/แก้ไขรายวัน
assets/js/calendar.js    ปฏิทิน
assets/js/settings.js    ตั้งค่า
assets/js/report.js      ฟอร์มรายงาน + ตัวอย่าง A4
assets/js/report-model.js  โมเดลเอกสารกลาง (ตัวอย่าง / Word ใช้ร่วมกัน)
assets/js/export-docx.js ส่งออก Word
gs.js                    โค้ด Apps Script (คัดลอกไปวาง)
```

## หมายเหตุ
- ไฟล์ Word ใช้ฟอนต์ **TH SarabunPSK** เครื่องที่เปิดไฟล์ต้องติดตั้งฟอนต์นี้
- Apps Script เก็บผลอ่าน Sheet ไว้ใน cache ไม่เกิน 1 ชั่วโมง การบันทึกผ่านเว็บและการพิมพ์แก้ใน Sheet จะล้าง cache เอง แต่ถ้า **ลบหรือแทรกแถวใน Sheet ด้วยมือ** ให้เปิด Apps Script เลือกฟังก์ชัน `clearCache` แล้วกด **เรียกใช้** (หรือรอ 1 ชั่วโมง)
- ระบบนี้ไม่มี login ใครที่ได้ URL ของ Apps Script ก็อ่านและเขียนข้อมูลได้ จึงไม่ควรเผยแพร่ลิงก์
