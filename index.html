Full-stack Developer

นายวรุณพร รัตนบุตรชัย

เจ้าหน้าที่ธุรการ โรงเรียนชุมชนวัดไทยงาม

ออกแบบและพัฒนาระบบนี้ด้วยตนเองทั้งหมด ตั้งแต่หน้าเว็บ ฐานข้อมูล ไปจนถึงการออกเอกสารราชการ เพื่อลดงานเอกสารซ้ำซ้อนของบุคลากรในโรงเรียน ให้บันทึกงานประจำวันได้ง่ายจากมือถือหรือคอมพิวเตอร์ และออกเอกสารเบิกค่าจ้างได้ในไม่กี่คลิก

ความสามารถด้านการเขียนโปรแกรม

Frontend

พัฒนาเว็บแอปด้วย React และ Next.js รวมถึง HTML, JavaScript และ Tailwind CSS รองรับทั้งมือถือและคอมพิวเตอร์ (Responsive Design)

Backend / API

เขียน API ด้วย Next.js (API Routes / Server Actions) และ Google Apps Script รับ-ส่งข้อมูลแบบ JSON พร้อมระบบ cache และ lock กันข้อมูลชนกัน

ฐานข้อมูล

ออกแบบฐานข้อมูลเชิงสัมพันธ์ด้วย MySQL และ PostgreSQL เขียนคำสั่ง SQL และจัดการ schema ผ่าน Prisma ORM รวมถึงใช้ Google Sheets เป็นฐานข้อมูลสำหรับงานขนาดเล็ก

ระบบออกเอกสาร

สร้างไฟล์ Word ตามแบบฟอร์มราชการ รองรับฟอนต์ TH Sarabun เลขไทย และการตัดคำภาษาไทย
